# 实验协议 v0.1

## 研究问题

在固定问题与实验条件下，回答的事实可靠性、证据使用与不确定性表达是否出现可重复的差异？本协议用于小规模试运行，不据此对整体临床能力排名。

## 一次实验如何定义

每个批次冻结问题集版本、提示词版本、评分规则和采集时间窗口。每条回答记录平台、模型标识、模型版本、API/产品入口、联网状态及重复序号。平台不公开版本时如实记为 `undisclosed`，不能自行猜测。

## 运行步骤

1. 选择同一题集与实验条件，事先写清比较假设。
2. 每个条件至少重复 3 次作为试运行；重复次数不是统计功效保证。
3. 使用新会话，避免旧对话影响答案；记录无法控制的个性化或产品行为。
4. 原文和失败信息按运行 ID 保存。重试产生新运行，不覆盖失败记录。
5. 先去除模型名称再评分，评分者对分歧进行复核；医学事实需要合适的参考依据和专业复核。
6. 汇总时同时给出题数、成功数、失败数、未评分数和各维度分布。
7. 从错误案例提出解释，再用控制变量实验检验，不能从一次错误直接推断内部原因。

## 比较边界

API 模型与同名消费产品分别报告。联网开关、提示词、采集日期不一致时，不把结果当作单一模型能力差异。问题集中已用于调参的题不能再充当独立留出集。

## 下一轮研究

冻结试运行题后补充独立留出题、双人评分及评审一致性统计。若样本不足，报告为探索性观察，不以漂亮百分比替代不确定性。
